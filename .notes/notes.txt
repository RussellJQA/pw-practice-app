Course exercises for "UI Automation Using Playwright with Typescript" (https://courses.testguild.com/training/ui-playwright/)

Dev Environment:

    Node.js
        node -v # Validate node version

    VS Code

    Git O(git-scm.com)
        git -v // Valdiate git version

    VS Code Playwright extension (Playwright Test for VSCode)

Install Demo Application: This project was cloned to my PC using:

    D:
    cd D:\dev\_ts\testguild     
    git clone https://github.com/bondar-artem/pw-practice-app
        // This pw-practice-app is a:
            // modified and more lightweight version of original application to practice UI Automation with Playwright
            //  at htps://github.com/akveo/ngx-admin
        // Both applications are MIT-licensed
    
    npm install pw-practice-app 
        If needed, add "--force"

    npm start // start the pw-practice-app running on http://localhost:4200

        ** Angular Live Development Server is listening on localhost:4200, open your browser on http://localhost:4200/ **

Within the resulting D:\dev\_ts\testguild\pw-practice-app folder:

    npm init playwright@latest --force
